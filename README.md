# 🛒 Simple Order Management System in Java

## 📌 Overview
This project is a *Java-based console application* that simulates a basic *Order Management System* using *Object-Oriented Programming (OOP)* principles and the *Java Collections Framework*.  
It allows users to create products, place orders, calculate total bills, and manage product stock efficiently — all through user input via the Scanner class.

---

## 🧩 Features
- Add multiple products dynamically
- Maintain product catalog and stock
- Create and manage customer orders
- Automatically calculate total bill
- Update stock after each order
- Display detailed order summaries
- Uses Scanner for real-time user input

---

## 🏗 Project Structure

### *Product Class*
Handles product details such as:
- Product ID  
- Product Name  
- Category  
- Price  

### *Order Class*
Manages customer order details including:
- Order ID  
- Customer ID  
- Order Date  
- List of ordered items (Product ID and Quantity)  
- Total calculation  

### *Main Class*
Provides the main functionality:
- Accepts input for products and stock  
- Creates an order for a customer  
- Adds products to the order  
- Displays product catalog  
- Shows order summary and total bill  
- Updates and displays stock levels  

---

## 🧠 Technologies Used
- *Java (JDK 8 or higher)*  
- *Scanner* for user input  
- *Collections Framework* (Map, List, HashMap, ArrayList)  
- *SimpleDateFormat* for date formatting
